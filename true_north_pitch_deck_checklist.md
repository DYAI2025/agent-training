# True North Pitch-Deck Checkliste
## Der Nordstern für professionelle Investoren-Pitch-Decks (2026 Standard)

Diese Checkliste repräsentiert den **perfekten, fast unerreichbaren Standard** für Pitch-Decks. Sie dient als QA-Richtlinie für die Autonomous Pitch Deck Agency.

---

## 🎯 OVERALL CRITERIA (100% = True North)

### A. IMMEDIATE IMPACT (30-Sekunden-Regel) - 15%
- [ ] **Hook in ersten 3 Sekunden**: Persönliche Geschichte + Problem + beeindruckende Metrik
- [ ] **Emotionale Verbindung**: Investor fühlt sofort "Das ist wichtig/groß"
- [ ] **Kognitive Resonanz**: Story aligniert mit Investor's mentalen Modellen
- [ ] **FOMO-Trigger**: Social Proof + zeitliche Dringlichkeit spürbar
- [ ] **Visuelle Dominanz**: 3-30-3-Prinzip (3-sec Visual Check, 30-sec Core Message, 3-min Deep Dive)

### B. STRUCTURAL PERFECTION (11-Slide-Struktur) - 15%
- [ ] **Slide 1 - Title**: Klar, memorabel, Positionierung sofort erkennbar
- [ ] **Slide 2 - Problem**: Spezifischer Pain Point, quantifiziert, unvermeidbar
- [ ] **Slide 3 - Solution**: Klare Lösung, nicht "Magie", konkreter Mechanismus
- [ ] **Slide 4 - Why Now**: Timing-Argument, Markt-Window, katalytische Ereignisse
- [ ] **Slide 5 - Market**: Bottom-Up TAM/SAM/SOM, keine Fantasy-Math
- [ ] **Slide 6 - Competition**: Ehrlich, differenziert, "Keine Konkurrenz" vermieden
- [ ] **Slide 7 - Product**: Demo/Screenshots, nicht "Coming Soon", User Value sichtbar
- [ ] **Slide 8 - Traction**: Echte Metrics, Trends nicht statische Daten, Growth Story
- [ ] **Slide 9 - Business Model**: Unit Economics (LTV:CAC ≥ 3:1), Payback <12 Monate
- [ ] **Slide 10 - Team**: Founder-Market Fit, relevante Erfahrung, keine "Advisor-Filler"
- [ ] **Slide 11 - Ask**: Klare Amount, Use-Case, Milestones, Runway

### C. VC-FRAMEWORK ALIGNMENT - 20%
- [ ] **Sequoia Standard**: Extreme Klarheit, "Clarity beats Cleverness"
- [ ] **a16z Standard**: Founder-Market Fit evident, Network Effects erkennbar
- [ ] **YC Standard**: 2-Satz-Test bestanden ("Was baut ihr? Für wen? Warum jetzt?")
- [ ] **Quantitative Benchmarks**: Seed ARR 0.25-1.5M, Series A 1.5-5M erreicht
- [ ] **Unit Economics**: LTV:CAC ≥ 3:1, Payback <12 Monate, Gross Margin >70%
- [ ] **Operation AI**: Model Centricity, Defensibility, Usage Metrics evident

### D. PSYCHOLOGICAL MASTERY - 15%
- [ ] **Storytelling-Arc**: Protagonist (Kunde) → Antagonist (Ineffizienz) → Produkt (Werkzeug)
- [ ] **Verlustaversion**: Problem so schmerzhaft, Nicht-Investieren = Verlust
- [ ] **Social Proof**: Kunden, Partner, VCs, Team-Track Record evident
- [ ] **Authority Signals**: Industry recognition, patents, publications, awards
- [ ] **Scarcity**: "Limited spots", "Exclusive access", "Time-sensitive"

### E. DESIGN EXCELLENCE - 10%
- [ ] **Kognitive Ergonomie**: Minimal Text, maximaler Visual Impact
- [ ] **Farbpsychologie**: Emotionale Farbwahl passend zur Brand/Industry
- [ ] **Typografie**: Hierarchie, Lesbarkeit, Professionalität
- [ ] **Data Visualization**: Komplexe Daten einfach, intuitiv, sofort verständlich
- [ ] **Consistency**: Einheitliches Design-System, Brand-Alignment

### F. QUANTITATIVE RIGOR - 10%
- [ ] **Bottom-Up Market Size**: Realistische Annahmen, keine Top-Down Fantasy
- [ ] **Cohort Analysis**: Retention, Churn, Expansion Revenue gezeigt
- [ ] **Unit Economics**: Customer Acquisition Cost, Lifetime Value, Payback Period
- [ ] **Growth Metrics**: MoM, YoY, Viral Coefficient, Sales Cycle Length
- [ ] **Financial Projections**: 3-5 Jahre, realistisch, keine Hockey-Stick ohne Basis

### G. REGIONAL/SECTORAL ADAPTATION - 5%
- [ ] **Cultural Fit**: DACH-Formalität vs. US-Narrativ passend zur Zielgruppe
- [ ] **Regulatory Awareness**: GDPR, SOC2, Industry-Specific Compliance
- [ ] **Local Market Knowledge**: Berlin VC-Szene, KfW, Deutschlandfonds integriert
- [ ] **Sector-Specific Metrics**: SaaS (MRR/Churn) vs. Deep Tech (Lab Data/TRL)
- [ ] **Local Competition**: DACH-specific competitors acknowledged

### H. REAL-WORLD VALIDATION - 10%
- [ ] **Customer Validation**: Pilot customers, case studies, testimonials
- [ ] **Technical Feasibility**: MVP exists, technical risk minimized
- [ ] **Team Execution**: Previous exits, domain expertise, track record
- [ ] **Market Traction**: Revenue, users, partnerships, distribution channels
- [ ] **Risk Mitigation**: Technical, market, execution risks addressed

## 📊 SCORING SYSTEM

### True North Annäherung berechnen:
```
Score = (Erreichte Kriterien / Gesamte Kriterien) × 100
```

### Kategorien:
- **90-100%**: Exceptional (Release-ready für Top-Tier VCs)
- **80-89%**: Excellent (Release-ready für Series A/B VCs)
- **70-79%**: Good (Nicht release-ready, needs iteration)
- **60-69%**: Acceptable (Major gaps, needs significant improvement)
- **<60%**: Poor (Complete rework required)

### Release-Kriterium:
**Minimum 80% True North Annäherung** für Kunden-Release

## 🔄 QA-PROZESS FÜR AGENTEN

### 1. Initial Pitch-Deck Erstellung
- Content Agent erstellt erstes Pitch-Deck
- Analyst Agent bewertet gegen True North Checkliste
- Score dokumentieren

### 2. Gap-Analyse
- Identifizierte Lücken kategorisieren (A-H)
- Priorisierte Verbesserungsmaßnahmen festlegen
- Maßnahme mit erwartetem Impact-Score versehen

### 3. Iterative Verbesserung
- Content Agent implementiert Verbesserungen
- Analyst Agent re-evaluiert gegen Checkliste
- Improvement-Maßnahme als POSITIV/NEGATIV markieren

### 4. Learning Integration
- Positive Maßnahmen → Learning Memory schreiben
- Negative Maßnahmen → Lessons Learned dokumentieren
- Pattern-Erkennung für zukünftige Pitch-Decks

### 5. Iteration bis 80%
- Prozess wiederholen bis 80% True North erreicht
- Bei jeder Iteration: Score-Tracking und Learning
- Final Release bei 80%+ mit Verbesserungs-Historie
